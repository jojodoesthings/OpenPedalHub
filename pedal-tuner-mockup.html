How the real version keeps the pedal set safe

It only listens

The app would read the same position reports Windows already receives from the pedals. It never sends anything back to them, and it does not touch firmware or calibration stored in the hardware.

Curves live on the PC

Dead zones and gamma are applied in software and sent to a separate virtual controller that games bind to. The pedals themselves keep reporting raw, unmodified values.

Closing it undoes everything

Quit the app and the pedals behave exactly as they do today. The worst case of a bug is a wrong value reaching the game, not a change to the pedal set.
